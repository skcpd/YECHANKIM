《오리지널 리콜: 초심 모험가 페스티벌》

선정 키워드: 근본이즘 · 필코노미 · 1.5가구 — 트렌드 코리아 2026의 10대 키워드 중 메이플 키우기의 IP 정체성과 타겟 라이프스타일에 가장 부합하는 3개를 선정했습니다.

01

이벤트 개요

컨셉 — 트렌드 코리아 2026의 '근본이즘' 키워드를 중심으로, 메이플스토리 원작의 클래식 맵·직업·사운드를 소환하는 노스탤지어형 이벤트. 방치형 게임 특유의 저부담 편의성은 유지하면서, 감성 연출(필코노미)과 시간 절약형 상품(1.5가구 라이프스타일)을 결합한다.
목적 — 기존 유저 리텐션 강화 및 결제 전환 극대화, 원작 IP 향수를 활용한 복귀 유저 확보.
기간 — 총 4주: 프리시즌 1주(티저·사전예약), 본편 2주(핵심 콘텐츠 오픈), 라스트콜 1주(마감 임박 리마인드 및 보상 정산).
02

트렌드 연계 포인트

키워드선정 이유게임 콘텐츠 연결
근본이즘 원작 '메이플스토리'의 클래식 자산(엘리니아, 커닝시티, 4대 직업)을 방치형으로 재해석한 게임 — 원조·오리지널 회귀 서사와 정체성이 정확히 일치 클래식 맵 리마스터, 오리지널 직업 스킨, 원작 보스(혼테일 등) 소환 레이드
필코노미 코디·스킨이 핵심 구매 동기인 게임 특성상, 기능이 아닌 '감정'을 파는 상품 설계가 유효 코디템에 스토리텔링 부여(예: "첫 모험 때 입었던 그 옷"), 추억 소환 컷신
1.5가구 자동전투·자동성장 장르 자체가 바쁜 1인 가구·맞벌이 유저의 '틈새 시간' 소비를 겨냥 — 짧고 부담 없는 참여 구조가 핵심 5~10분 세션으로 완결되는 일일 미션, 자동 진행 비중이 높은 주간 콘텐츠
03

핵심 콘텐츠 / 미션 구성

구분콘텐츠참여 방식보상 연동
일일초심 던전 클리어자동전투 방치 진행 (조작 불필요)성장 재화, 출석 보상
주간추억의 조각 수집주 1회 저부담 자동 미션클래식 코디 재료 교환
메인(격주)클래식 보스 레이드(혼테일 등)협동/솔로 선택 가능, 난이도 단계별시즌 한정 장비·타이틀
서브오리지널 룩 코디 뽑기인게임 재화 또는 유료 재화 사용확률형 한정 스킨

난이도 단계를 두어(입문 / 도전) 신규·복귀 유저와 코어 유저가 같은 이벤트 안에서 각자의 속도로 참여하도록 설계한다.

04

보상 설계

무료 트랙

  • 초심 던전 클리어 성장 재화
  • 15일 연속 출석 시 한정 칭호 "초심을 기억하는 자"

유료 트랙 (과금 유도 포인트)

  • 오리지널 모험가 시즌패스 — 무료/유료 이원화, 유료 구매 시 전용 코디 즉시 지급 + 진행 보상 2배
  • 클래식 코디 확률형 뽑기 — 천장(보장 획득) 시스템 포함, 확률 정보 인게임 명시
  • 초심 던전 자동 2배속 이용권 — "시간을 사는" 상품으로 1.5가구·바쁜 유저 타겟 (필코노미+1.5가구 결합 상품)

무료-유료 보상 격차는 '시간 단축'과 '희귀 코디'로 한정하고, 전투력 직결 아이템은 과도하게 차등을 두지 않아 무과금 유저의 이탈을 방지한다.

05

UI / 연출 컨셉

톤앤매너 — 세피아톤 필터 + 클래식 픽셀 아트 오버레이. 오리지널 런칭 당시 UI 프레임을 오마주한 이벤트 전용 스킨.
배너 카피 — "다시, 처음 그 마음으로" — 초기 캐릭터 일러스트와 현재 캐릭터를 나란히 배치한 Before / After 구도.
연출 — 초심 던전 진입 시 클래식 로딩 화면과 오리지널 BGM 재생, 클리어 시 추억 소환 컷신 삽입.
06

커뮤니케이션 전략

  • 사전 공지 — 이벤트 시작 1주 전 클래식 UI 스크린샷을 티저로 공개해 노스탤지어 자극
  • SNS — "내 첫 캐릭터 공개" 해시태그 이벤트로 UGC 유도 (필코노미형 감성 참여)
  • 커뮤니티 — 장기 유저 인터뷰·추억담 콘텐츠 발행, 개발자 노트를 통해 '초심' 서사를 공식화
  • 인플루언서 — 원작 메이플스토리 장기 유저 크리에이터를 섭외해 '그때 그 시절' 회고 콘텐츠 제작 의뢰
